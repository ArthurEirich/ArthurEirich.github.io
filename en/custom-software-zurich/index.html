What I can help with

Business applications and internal tools

I help SMEs replace manual processes with database-backed applications. That can include approval flows, internal tools, data import and export, and reports that draw on reliable shared data.

Java, Spring Boot and system integration

I develop backends with Java and Spring Boot, design REST APIs and connect existing systems. We discuss data models, permissions, integrations and the architecture the project calls for.

Prototypes, MVPs and further development

I’m a senior software engineer with many years of experience. I can advise on architecture, scope a first release, and maintain or extend software by agreement. Larger projects can be broken into stages with clear acceptance criteria.

What a solution might look like (hypothetical examples)

An SME could log requests in an internal app, assign approvals by role and pass the result to another system via a REST API. Another possibility is bringing data from two tools together to produce a recurring report.

How it works

Tell me what outcome you need, which systems are involved and what a first release should do. We discuss requirements, interfaces and acceptance criteria before defining scope and preparing a quote.

I’m based in Zurich Oerlikon and work with businesses in the city and nearby. We can plan the project remotely. Support in English and German.

The starting price covers a small, clearly scoped project. The quote depends on the features, data, existing systems, uncertainties in the work and agreed deliverables.
