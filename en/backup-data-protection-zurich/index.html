What I can help with

Choose a backup plan you can use

The 3-2-1 rule means three copies including the original, on two kinds of media, with one copy kept off-site. For essential documents or photos, that could be your computer, an external drive and a cloud backup.

Set up automatic backups

We can compare Windows backup options, Time Machine for Mac, phone backups, external drives, NAS storage and cloud backup. The choice depends on which files matter and when the backup can run. I’ll also explain the difference between syncing and backing up.

Test a backup and restore files

I help check a sample file and restore data from existing backups, including when you move to a new computer. Recovering data from physically damaged storage is a separate specialist service.

How it works

We identify the devices and files you want to protect and check which copies already exist. Once the chosen backup is configured, we use a sample file to practise restoring it and check how you can tell whether a backup ran.

Frequently asked questions

Can you recover all my lost files?

I can help restore data from existing, readable backups. I don’t provide forensic recovery or repair damaged storage.

Is syncing to the cloud enough?

Sync keeps devices up to date and can pass a deletion on too. We’ll check whether a separate backup or suitable version history is useful.

Can you help me move to a new computer?

Yes. We can check the backups you already have, transfer the files you need and verify important documents on the new PC or Mac.
